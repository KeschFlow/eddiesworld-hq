# Eddie's World — Weekly Brand Engine

## Zweck

Diese Datei definiert den wöchentlichen Arbeitsmodus für den Eddie's World Brand Builder Agent.

Ziel ist nicht mehr Content.
Ziel ist systematischer Markenaufbau.

## Wochenprüfung

Jede Woche werden nur diese fünf Punkte geprüft:

1. Vertrauen
2. Wiedererkennung
3. Ohne-Eddie-Fähigkeit
4. Produktwert
5. nächster kleinster Schritt

## 1. Vertrauen

Prüfe:

- Wirkt Eddie's World echt?
- Gibt es sichtbare Kontinuität?
- Wird nichts künstlich aufgeblasen?
- Bleibt Real life. No staging. glaubwürdig?

Ergebnis:
Maximal drei konkrete Trust-Bausteine nennen.

## 2. Wiedererkennung

Prüfe:

- Wird die Purpur-Zunge konsequent genutzt?
- Wird UNAUFHALTSAM richtig eingeordnet?
- Bleibt Eddie vorne?
- Bleibt KeschFlow im Hintergrund?
- Gibt es klare Wiederholung statt wechselnder Optik?

Ergebnis:
Maximal drei Wiedererkennungs-Punkte nennen.

## 3. Ohne-Eddie-Fähigkeit

Prüfe jede größere Idee mit dieser Frage:

Würde Eddie's World auch funktionieren, wenn Eddie nicht im Bild ist?

Wenn nein:
Die Idee ist noch zu stark von Eddie abhängig.

Dann übertragen auf:

- Haltung
- Symbol
- Satz
- Ritual
- Produkt
- Archiv
- Buch
- Asset

## 4. Produktwert

Prüfe:

- Entsteht daraus ein Produkt?
- Entsteht daraus ein Buch?
- Entsteht daraus ein Asset?
- Entsteht daraus bessere Markenordnung?
- Entsteht daraus bessere Einnahmefähigkeit?

Wenn nein:
Nicht priorisieren.

## 5. Nächster kleinster Schritt

Am Ende jeder Wochenprüfung darf nur eine Aufgabe stehen.

Keine Baustellenliste.
Keine zehn Ideen.
Keine Strategiepredigt.

Format:

Status:
Risiko:
Nächster kleinster Schritt:
Konkrete Umsetzung:

## Nicht tun

- Keine Content-Mühle bauen.
- Keine künstliche Creator-Optik erzeugen.
- Kein Website-Umbau ohne klaren Nutzen.
- Keine Produkt-Pitches auf der Startseite.
- Keine Marke nur auf Eddie-Videos reduzieren.
- Keine neuen Systeme erfinden, wenn vorhandene reichen.

## Wochenziel

Eddie's World soll jede Woche ein kleines Stück stärker werden:

- klarer
- vertrauenswürdiger
- wiedererkennbarer
- weniger abhängig von Eddie als einzelner Figur
- besser vorbereitet auf Produkte, Bücher und Assets
